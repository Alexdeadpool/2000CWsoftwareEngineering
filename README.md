Kept simple and easy because this is a locally hosted app and it should be simple to get in to the app since the purpose is more about wireframes.

Features:
Login screen with simple validation checks
User can make bookings for different room types
User can make bookings specific dates and times
User can make multiple bookings but they are unapproved by default
User can see all their bookings with options to cancel them
User can return to dashboard at any time throughout the app on screens flowing past the dashboard
User has the option to sign out when on the dashboard screen meaning they onlly need to press two buttons for easibilty.
